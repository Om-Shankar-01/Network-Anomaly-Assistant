# Phase 8: The Interface (Frontend Dashboard) - Detailed Execution Plan

## 📌 Phase Overview
Phase 8 constructs a state-of-the-art, visually wowed frontend web application for Network Reliability Engineers (NREs) and incident responders. It brings together all 7 backend phases into an interactive command center featuring live topology blast-radius visualizers, 3-way evidence matrices, Bayesian root-cause rankers, markdown incident report viewers, and real-time audit trail timelines.

## 📅 Day-Wise Schedule & Task Breakdown

### 🗓️ Day 1: Design System, UI Shell & REST Integration Layer (5 Hours)

#### Task 1.1: Design System & Styling Foundation (1.5 Hours)
- Setup modern CSS design system tokens:
  - Theme: Deep Glassmorphism Dark Mode (`#0B0F19` obsidian background, `#1E293B` panel cards, `#6366F1` indigo / `#8B5CF6` purple gradient accents).
  - Google Font: `Inter` or `Outfit` for crisp typography.
  - Micro-animations, subtle glow shadows, and responsive layout grid.

#### Task 1.2: Main Navigation & Metric Header Cards (1.5 Hours)
- Header with System Health Status (`/api/v1/system/health`), System Uptime, Active Incident Counter, and JWT Authentication status.
- Primary navigation tabs:
  1. 🌐 **Topology Blast Radius**
  2. 🧠 **Causal Inference & 3-Way Evidence Matrix**
  3. 📄 **Explainable Assistant & CLI Commands**
  4. 📜 **Audit History & Compliance Post-Mortem**

#### Task 1.3: Backend REST Client Services (2.0 Hours)
- JavaScript API service wrappers fetching live backend endpoints:
  - System Health: `GET /api/v1/system/health`
  - DAG Topology: `GET /api/v1/causal/dag/{deviceId}`
  - Incident Context: `GET /api/v1/explainability/context/{deviceId}`
  - Explainable Assistant: `POST /api/v1/assistant/explain/{deviceId}`
  - Audit History: `GET /api/v1/audit/incidents/{incidentId}/history`

---

### 🗓️ Day 2: Topology Blast Radius Canvas & 3-Way Evidence Matrix (5 Hours)

#### Task 2.1: Interactive Topology & Blast Radius Visualizer (2.5 Hours)
- Render interactive topology graph nodes and directed dependency edges (Core $\rightarrow$ Distribution $\rightarrow$ Edge).
- Color-coded node statuses:
  - 🔴 **Primary Root Cause Node** (Pulse animation & red glow)
  - 🟡 **Impacted Blast Radius Nodes** (Amber glow)
  - 🟢 **Healthy Dependent Nodes** (Emerald green)

#### Task 2.2: 3-Way Evidence Matrix Card (1.5 Hours)
- Dedicated 3-column evidence layout:
  - 🟢 **Confirmed Evidence**: Hard facts (`LINK_DOWN` alerts, `CONFIG_CHANGE` logs).
  - 🟡 **Correlated Signals**: Statistical associations (`cpu_usage = 96.8%`, Granger $p < 0.05$).
  - 🔴 **Missing Evidence**: Signal gaps (`HEARTBEAT_GAP` silent timeout).

#### Task 2.3: Bayesian Root-Cause Leaderboard (1.0 Hour)
- Ranked candidate bar chart showing posterior probability percentages (e.g., `router-core-01`: 91.7%) with confidence badges (`HIGH` / `MEDIUM` / `LOW`).

---

### 🗓️ Day 3: Explainable Assistant Report Viewer & Audit Timeline (5 Hours)

#### Task 3.1: Live Markdown Report Viewer (2.0 Hours)
- Renders Markdown report generated by Python LLM / Gemini engine.
- Syntax-highlighted CLI diagnostic commands with 1-click **"Copy CLI Command"** buttons.

#### Task 3.2: Immutable Audit Trail Timeline Feed (1.5 Hours)
- Chronological timeline feed rendering state transitions:
  $$\text{HEALTHY} \longrightarrow \mathbf{DETECTED} \longrightarrow \mathbf{CORRELATED} \longrightarrow \mathbf{ROOT\_CAUSE\_CONFIRMED} \longrightarrow \mathbf{RESOLVED}$$

#### Task 3.3: Phase 8 End-to-End Dashboard Verification (1.5 Hours)
- Run full interactive test: login via JWT, select incident device, explore live topology, trigger LLM assistant, and inspect real-time audit feed!
